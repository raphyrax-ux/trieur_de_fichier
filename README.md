# Projet 1 : Trieur de fichier
Script qui prend un dossier1 contenant une multitude de fichiers et renvoie un dossier2 contenant tout les fichiers du dossier1 triés par catégorie 5image, Document, Code etc.)

## Utilisation
- Run le fichier generer_dossier.py pour créer un dossier de test
- Run le fichier tri.py pour trier le dossier

## Fonctionnalités
- Tri par extension
- Renommage des doublons (`photo (1).jpg`)
- Rapport CSV (nom, type, taille, date, chemin)

## Critiques
- Programme intéressant mais qui n'est pas bien organisé -> mauvais découpage des fonctions (code réutilisé)
